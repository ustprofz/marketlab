For teachers · Suggested grades 9–12

A real question makes a better lesson.

Use a repeatable practice dataset for a shared class investigation, or connect Yahoo data for a discussion about current markets. No student account is required. Activities emphasize reasoning and data literacy rather than picking winning stocks.

01
Finance · 10–15 minutes

From familiar brands to market data

Begin with a company students recognize and practice reading a financial chart.

  1. Identify ticker, currency, source, and observation date.
  2. Estimate a percentage change, then compare with the calculated change.
  3. Explain why a higher share price does not by itself identify a bigger company.
02
Statistics · 15–20 minutes

Price is a level. Return is a change.

Use a return histogram to connect financial data with descriptive statistics.

  1. Compare the mean and median return.
  2. Change the number of histogram bins. Does the data change?
  3. Use sample SD to describe variability, and name a limitation of the sample.
03
Data analytics · 20–25 minutes

Different prices. A fair comparison.

Make a claim using indexed prices and correlation of returns.

  1. Predict how two companies might move together.
  2. Compare indexed prices and the return scatterplot.
  3. Download the data and defend a claim with evidence and a caveat.

A short vocabulary bridge

Close
The provider's closing-price field for a bar, in its reported currency.
Adjusted Close
Yahoo's corporate-action-adjusted price field. Read provider methodology before treating it as investment performance.
Return
New selected price ÷ previous selected price − 1.
Sample SD
Spread around the mean, using n − 1. This site does not annualize it.
Correlation
Pearson's r for matched returns; undefined if one series has no variability.
Volume
Reported trading quantity for a bar. A missing quantity is not zero.

Make it your classroom

  • Give a “data detective” mission: identify source, dates, units, and missing values before calculating.
  • Use share links so students begin with the same symbols, window, and price basis.
  • Download a CSV to keep a fixed dataset; refreshed Yahoo data can change between lessons.
  • Bring a local CSV to Explore when a network or provider is unavailable.
  • Assess the explanation, chart reading, and limitations—not investment profits.

Data sources, timing, and calculation notes

Practice mode: deterministic simulated prices ending in 2025, not actual company prices. Its weekday calendar is illustrative. Practice CSV files identify the data as SIMULATED.

Yahoo mode: a separately hosted Python service uses yfinance. Data may be delayed, incomplete, cached, or temporarily unavailable. Auto-refresh polls every 60 seconds; intraday server caching is 60 seconds and daily caching is 5 minutes. Retrieval time and market observation time are different. This is not a guaranteed real-time exchange feed.

Price basis: the quote and OHLC fields use the provider's Close/quote values; the chart and statistics use the selected Close or Adjusted Close field. The Python adapter requests auto_adjust=False to keep those fields separate. No missing adjusted value is silently replaced with Close.

Statistics: price change is first-to-last selected price change. Returns use consecutive valid positive prices; sample SD uses n − 1 and is not annualized. Correlation uses consecutive shared timestamps, not price levels. Missing/nonpositive selected prices are excluded from analytics and retained in the CSV.

Local CSV: imported data stay in the browser and are labelled user-imported, regardless of any original Source column. Files need Timestamp/Date and Close columns. Optional fields include Open, High, Low, Adj Close, and Volume. Comparison is available for two market/practice series; the first version's CSV import is for single-series exploration.

Provider terms: yfinance is independent of Yahoo. Its documentation describes research/education use and notes Yahoo Finance API personal-use limitations; the site operator must check rights before publicly redistributing provider data. Read provider/library guidance ↗
