# Start here: Market Lab

This is the complete GitHub project, including the static website and a Python/yfinance service.

1. Upload the extracted contents to a new GitHub repository. Keep `docs/`, `backend/`, and `render.yaml` at the repository root.
2. In GitHub **Settings → Pages**, choose **Deploy from a branch → main → /docs**, then Save. This publishes the website with simulated practice data.
3. For actual Yahoo data, deploy the included Python service on Render. `render.yaml` provides a Blueprint; `README.md` also explains manual setup. Review data-use rights before public redistribution.
4. Edit `docs/config.js` in GitHub and set `apiBase` to the deployed Python service URL. Commit, wait for Pages to redeploy, and reload.
5. Choose Yahoo data and confirm the source banner and market observation date. Quotes may be delayed; 60-second refresh is not a guaranteed real-time exchange feed.

Read `README.md` for illustrated-by-command setup steps, troubleshooting, calculation notes, and source documentation. The printable teacher guide is `docs/teacher-guide.html`. Engagement ideas are in `ROADMAP.md`.

The top of the website includes Jiang (Will) Zhang, the complete faculty title and LinkedIn link, the UST logo, Opus College of Business, The Opus Way of Teaching, and VIBE Lab.
